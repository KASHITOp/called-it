## Phase Goal

> ROADMAP Phase 1 goal (verbatim): "On or before 1 Dec 2026, a baseline-only Q3 FY27 revenue call for DMART, ETERNAL and TITAN is locked in an append-only, hash-chained ledger and witnessed by a GitHub commit and an OpenTimestamps proof. The call uses only data that was public at the lock instant, and the phase includes everything that cannot be changed once a lock exists."

<objective>
Build the Walking Skeleton end to end on SQLite (see SKELETON.md). Starting from a fresh clone, `uv sync` installs the workspace and `alembic upgrade head` creates the append-only `predictions` table. `nowcast rules` then appends a hash-chained `rules` record, and `nowcast ledger export` writes it to `ledger.jsonl`. Its SHA-256 is reproduced by golden vectors in both Python and JS. The plan then hardens the hash contract and ledger integrity: forks, triggers, export rules and typed columns.

Purpose: the `calledit-ledger-v1` spec, the record shape and the ledger-file format are the phase's biggest one-way doors. They become permanent at the first live write, which happens in Plan 01-12. Building and testing them first, across both languages, finds any architectural dead end after one commit.
Output: the DB layer, the Alembic 0001 migration, the ledger package, the CLI skeleton, the shared golden vectors and the `web/` JS test.
</objective>
