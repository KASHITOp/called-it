## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local repo -> public GitHub | Every committed byte becomes public permanently |
| GitHub secret -> Actions runner logs | The DB credential is present in a shared, public log context |
| workflow_dispatch inputs -> shell | Free-text inputs could inject commands |
| rehearsal -> live | Scratch runs share the Supabase project and the repo with the live ledger |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-40 | Information disclosure | first push | high | mitigate | preflight_publish.py scans tracked files and pushed history for connection strings and Supabase hosts, and checks that .env is ignored, before `git push` (D-03). It prints paths only |
| T-01-41 | Information disclosure | lock.yml logs | high | mitigate | The secret is set only in step-level env. There is no `set -x`. Fixed error messages come from settings, db check and env.py. The rehearsal log is checked for `supabase.com` |
| T-01-42 | Tampering / Elevation of privilege | workflow inputs | high | mitigate | Choice inputs only, passed through `env:` and never interpolated into `run:`. No pull_request_target |
| T-01-43 | Tampering | rehearsal vs live | high | mitigate | Settings forbid non-live envs from naming `calledit` or writing `ledger/`. Rehearsal pushes only to rehearsal-ledger. The isolation checks run after the rehearsal (P6 prohibition) |
| T-01-44 | Tampering | git witness history | high | mitigate | A ruleset on main blocks force-push and deletion. OTS proofs are independent of git |
| T-01-45 | Repudiation | OTS stamp input | medium | mitigate | The exact head bytes, with no newline, are written by write_head_bytes. `sha256sum` must equal the head hash before stamping. Existing proofs are never overwritten |
| T-01-46 | Tampering | third-party actions | medium | mitigate | Every action is pinned to a commit SHA with its tag in a comment. `permissions` are kept minimal per workflow |
| T-01-SC | Tampering | npm/pip/cargo installs | high | mitigate | The runner installs with `uv sync --locked --group ots` from the reviewed lockfile; opentimestamps-client 0.8.0 was approved in Plan 01-01 |
