- **LEAK-01** (unclassified; review manually). Covered by @example cases, but left unresolved for the verifier.
- **LEAK-02** (unclassified; review manually). Assumed edges: a leaky reader that raises instead of returning wrong rows (it would be "caught" by an error, not by an assertion), and pytest exit code 2 on collection errors in the subprocess. The meta-test accepts only exit 1. This edge is left unresolved for the verifier.
- **LEAK-03** (unclassified; review manually). Assumed edges: IST/UTC conversion across the year boundary (31 Dec 18:30Z), date-only events exactly at D 00:00 IST, and Windows machines without tzdata. These are covered across tests/leakage/test_time_boundaries.py (Plan 01-03), test_reader.py and test_baseline_boundaries.py, but left unresolved for the verifier.
